动态素材说明（本目录无需图片文件）
==================================
以下动态效果按素材规格表 2.5 用引擎实现，不需要生成图片素材：

1. 江水滚动  - 使用水纹瓦片 + motion_mirroring 平铺滚动（Godot）或材质偏移（Unity）
2. 雾 / 烟 / 火星 / 灰烬 - 使用粒子系统（CPUParticles2D / Particle System），无需图片
3. 灯笼 / 旗帜摆动 - 3 帧摆动循环可复用 场景物件 中的灯笼素材，或用 Swing 脚本旋转模拟
4. 飞鸟 - 建议用 背景 图内的飞鸟剪影裁切，或 4 帧手绘循环（登记 TODO）
5. 窑火 - 用 光影/glow_soft_橙火.png 做光晕 + 粒子火星，火苗 4 帧手绘（登记 TODO）

粒子参数建议：雾=低透明度慢速大范围；烟=上升+膨胀+淡出；火星=短寿命+重力+橙色；灰烬=大量小颗粒缓慢飘落。
