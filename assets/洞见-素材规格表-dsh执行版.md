# 《洞见》素材规格表（DeepSeek Harness 执行版）

> **文档用途**：本表是《洞见-Godot-DeepSeekHarness-执行规格书.md》第 8 章的详细补充，供 AI 开发代理（dsh）执行素材规划、占位生成、验收与后续替换。
> **关系**：Godot 规格书是开发主文档；本表只讲"素材要长什么样、做多少、怎么算合格"。
> **执行顺序**：先按第 6 章做占位 → 按第 7 章做正式素材 → 每类素材按第 6.4 节验收。
> **整理日期**：2026-09-07

---

## 第 1 章 素材生产总原则（所有素材必须遵守）

| # | 原则 | 执行方式 |
|---|---|---|
| 1 | 占位先行 | 所有素材先用 ColorRect 色块占位（Godot 规格书 4.5），不阻塞开发；正式素材就位后按同名替换 |
| 2 | 色板锁定 | 先定色板（第 5 章），所有像素素材只从该关色板取色，禁止随手取色 |
| 3 | 剪影可读 | 每个角色/建筑先画纯色剪影确认"剪影能认出是谁"，再上细节 |
| 4 | 用色克制 | 角色 ≤8 色（含描边）；建筑 ≤12 色；远景剪影 2-3 色 |
| 5 | 代码演出优先 | 雾=粒子、水=滚动、光=灯光闪烁，**不做**帧动画；帧动画只给角色/飞鸟/火苗 |
| 6 | 低帧率 | 循环动画 6-12fps（走路 10fps、待机 6fps、场景 8fps） |
| 7 | 像素锐利 | Nearest 过滤 + 像素对齐 + 1px=1 世界单位（project.godot 已设） |

## 第 2 章 像素基础规范

| 项目 | 规格 | 说明 |
|---|---|---|
| 视口 | 640×360（2 倍输出 1280×720） | 精致感需要更多像素空间；若性能紧张可降 480×270 |
| 像素密度 | 1px = 1 世界单位 | 全项目统一 |
| 纹理过滤 | Nearest（Point） | project.godot：`default_texture_filter=0` |
| 像素对齐 | 开启 | `snap_2d_transforms_to_pixel` / `snap_2d_vertices_to_pixel` |
| 色板 | 每关 48-64 色 | 全局共享基础色 + 每关时代变体（第 5 章） |
| 动画帧率 | 6-12 fps | 低帧率是像素风味，禁止 30fps 生硬动画 |
| 视差 | ParallaxBackground 五层 | motion_scale 0.05/0.2/0.5/0.9/1.3 |
| 光照 | PointLight2D + CanvasModulate + WorldEnvironment | 每关一套 LightRig |

## 第 3 章 人物素材规格

### 3.1 主角陈默

| 项目 | 规格 | 说明 |
|---|---|---|
| 画布尺寸 | 高 48px、宽约 24px | 预留服装细节空间 |
| 服装 | 全流程 1 套：V1 现代装（不做换装） | 时代差异只由 NPC/场景承担（2026-09-07 决定） |

## 第 4 章 场景素材规格

### 4.1 Tileset 尺寸规格

| Tileset | 瓦片尺寸 | 用途 |
|---|---|---|
| 地形层 | 32×32 | 地面、台阶、梯坎、洞壁 |
| 建筑层 | 64×64 | 吊脚楼、窑炉、排门店铺、城墙 |
| 装饰层 | 16×16 | 草、花、石、苔、裂痕、瓦砾、旗帜、灯笼 |
| 前景剪影 | 128×64 大块 | 飞檐、栏杆、树枝（压暗 30%） |
| 远景剪影 | 任意大图 | 山城、大桥、远山（2-3 色单色剪影） |

### 4.2 五层视差素材明细（每层做什么、细节密度要求）

| 层 | motion_scale | 内容 | 细节要求 | 动态元素 | 占位色 |
|---|---|---|---|---|---|
| 天空层 | 0.05 | 天色渐变 + 云 + 飞鸟 | 大色块渐变即可，像素数少 | 雾带（CPUParticles2D）、飞鸟（4 帧） | 按关色调渐变 |
| 远景层 | 0.2 | 江对岸山城剪影 / 远山窑烟 / 跨江大桥 | 2-3 色剪影，**不要**细节 | 索道缆车、航船（PathMover） | 暗紫剪影 |
| 中景层 ★ | 0.5 | 吊脚楼群 / 窑炉棚架 / 排门店铺 / 洞壁 | **细节主场**：木纹、砖纹、窗棂、瓦片、招牌；建筑 ≤12 色 | 江水（motion_mirroring）、轻轨、窑烟 | 关主色调 |
| 近景层 | 0.9 | 梯坎 / 街市 / 茶馆码头 / 避难人群 | 中等细节：32px 瓦片 + 16px 装饰 | 灯笼摆动（Swing） | 关主色亮档 |
| 前景层 | 1.3 | 飞檐 / 栏杆 / 树枝剪影 | 暗色剪影大块，压暗 30% 制造画框感 | 树枝摆动（Swing） | 近黑 |

### 4.3 装饰层清单（精致感关键，必须做）

| 装饰瓦片 | 使用场景 |
|---|---|
| 草簇、野花 | 古镇、窑场边缘 |
| 青苔、裂痕 | 古镇石阶、防空洞洞壁 |
| 瓦砾、碎砖 | 窑场、防空洞 |
| 石纹 | 梯坎、码头 |
| 木纹 | 吊脚楼、店铺 |
| 水面波光（2 帧） | 江水 |
| 苔藓吊脚、爬山虎 | 吊脚楼群（重庆特色） |

> 判定：任何地形层不能是纯色平面，必须叠装饰层；每屏装饰密度 ≥ 3 种。

### 4.4 动态素材表

| 素材 | 实现方式 | 素材需求 |
|---|---|---|
| 江水 | motion_mirroring 滚动 | 1 张 64×32 水纹瓦片 + 2 帧波光可选 |
| 灯笼/旗帜 | Swing 摆动脚本 | 3 帧静态摆动循环（含光晕点） |
| 飞鸟 | 4 帧循环 | 16×12px 剪影，2 色 |
| 索道缆车/航船 | PathMover | 1 张 32×24px 剪影 |
| 轻轨（现代关） | PathMover 循环平移 | 1 张 96×32px 剪影 |
| 窑火 | 4 帧火苗 + PointLight2D | 火苗 32×32，橙色 5 色 |
| 雾/烟/火星/灰烬 | CPUParticles2D | **无需图片素材** |

## 第 6 章 素材优先级与验收标准

### 6.1 优先级

| 优先级 | 素材 | 交付物 | 阻塞点 |
|---|---|---|---|
| P0 | 主角占位块 + 5 套服装色块、NPC 占位块 | 场景可用 | 无（Phase 1-7 用） |
| P1 | 五关 tileset 占位（按第 5 章色板配色的色块板） | 场景分色 | 无（Phase 8 用） |
| P2 | 正式像素素材（按第 3/4 章规格绘制或 AI 生成+手修） | 最终美术 | 不阻塞开发，登记 TODO |

### 6.2 验收标准（正式素材每类必查）

| 检查项 | 标准 |
|---|---|
| 剪影可读 | 缩放到 50% 仍能认出角色/建筑身份 |
| 用色 | 角色 ≤8 色、建筑 ≤12 色、远景 2-3 色（与第 5 章色板一致） |
| 动画闭环 | 走路/待机首尾帧无跳变；帧率 6-12fps |
| 像素锐利 | Nearest 下无模糊、无半像素偏移 |
| 装饰密度 | 每屏 ≥3 种装饰元素 |
| 尺寸合规 | 人物 48px、瓦片 32/64/16px、前景剪影 128×64 |
| 时代一致性 | 素材颜色取自对应关色板（第 5 章） |

### 6.3 正式素材替换路径（dsh 执行）

```
assets/
  sprites/
    characters/  player/  (player_v1.png … player_v5.png + 帧表)
                 npcs/    (flyer_lady.png … )
    tilesets/    terrain_01.png … terrain_05.png
                 buildings_01.png … buildings_05.png
                 decorations_16.png
                 silhouettes.png
    vfx/         glow_soft.png  window_light.png
  audio/         （第 9 章占位说明）
```

- 正式素材文件名与占位对象同名（`NPC_FlyerLady` → `flyer_lady.png`），替换时直接换 Sprite 资源。
- 帧表约定：单行序列帧 PNG，从左到右按帧序排列；Unity/Godot 中按 SpriteFrames 切分。
