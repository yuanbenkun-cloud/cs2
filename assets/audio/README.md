# 音频制作与接入说明

五关主题配乐、五关环境循环和核心反馈音效均已接入全局 `AudioManager`。音乐和环境声会随场景交叉淡入淡出，对话出现时自动降低音量，避免压住文字节奏。

## BGM（每关 1 循环）
- 01 洪崖洞·迷途（现代·夜）：冷色钟音与不安低音，搭配雨夜底噪。
- 02 磁器口·生存之重（古代·窑场）：低鼓、金属泛音与窑火爆裂声。
- 03 中山古镇·规矩与诚信：克制的五声音阶拨奏，搭配屋檐雨声。
- 04 防空洞·黑暗中的脊梁：低频心跳、远处警报与洞内空气声。
- 05 洪崖洞·归来（现代·晨）：逐步上行的明亮动机、江风与晨鸟。

## 音效
脚步 / 交互确认 / 心碎（心烦-1）/ 锤凿 / 轰炸呼啸 / 警报

## 环境音
雨夜 / 窑火 / 屋檐雨 / 防空洞警报 / 江风晨鸟

## 当前实现

- 已接入：脚步、跳跃、交互确认/错误、追逐提示、锻造、货损、挡板受击、爆炸、记忆收集。
- 音频总线：`SFX / UI / Ambient / Music`；ESC 设置菜单可分别调整总音量、音乐、环境声、音效和界面音。
- 当前反馈素材来自 Kenney CC0 包；发行所用副本与许可见 `assets/audio/sfx/` 和 `assets/audio/KENNEY-CC0-LICENSE.txt`，完整源包保留在 `assets/vendor/` 但不打入发行版。
- BGM 与环境循环由 `tools/generate_audio_loops.py` 以数值合成方式原创生成，不使用外部采样。成品及参数清单见 `assets/audio/generated/`；格式为 22.05 kHz、16-bit、立体声 WAV，每条 24 秒。
