# 音频制作与接入说明

菜单、五关和结尾使用玩家提供的新音乐；关卡环境声也已改用玩家提供的录音。音乐和环境声经全局 `AudioManager` 分层播放，对话出现时自动降低音量。开场视频另存于 `assets/video/edit/`：画面保持不变，原音轨保留并混入新的主界面 BGM。原始视频文件未修改；进入菜单后同一首曲子按时间点接续播放。

## 新 BGM
- 开场视频 / 主菜单：`user_music/主界面-新配乐.ogg`（片头另有带该曲混音的视频文件）
- 第 1～5 关：`user_music/第1关-追逐.ogg` 至 `user_music/第5关-归来.ogg`
- 结尾：`user_music/结尾-新配乐.ogg`

## 音效
脚步 / 交互确认 / 心碎（心烦-1）/ 锤凿 / 轰炸呼啸 / 警报

## 环境音
菜单：洪崖背景；第一关：江岸汽笛；第二关：窑火、窑场风、锤陶土；第三关：河流、水声、船夫吆喝；第四关：洞内环境、远处轰炸；第五关和结尾：江岸汽笛。第四关的间断防空警报作为独立玩法提示保留。

## 当前实现

- 已接入：脚步、跳跃、交互确认/错误、追逐提示、锻造、货损、挡板受击、爆炸、记忆收集。
- 音频总线：`SFX / UI / Ambient / Music`；ESC 设置菜单可分别调整总音量、音乐、环境声、音效和界面音。
- 当前反馈素材来自 Kenney CC0 包；发行所用副本与许可见 `assets/audio/sfx/` 和 `assets/audio/KENNEY-CC0-LICENSE.txt`，完整源包保留在 `assets/vendor/` 但不打入发行版。
- 玩家提供的桌面 WAV 已转换为 44.1 kHz Ogg Vorbis，以减少导出体积；源文件没有改动。旧版配乐和环境音仍留在工程中供回退，但不再被关卡音频路由调用。具体源文件映射见 `user_music/README.md` 和 `user_ambience/README.md`。
