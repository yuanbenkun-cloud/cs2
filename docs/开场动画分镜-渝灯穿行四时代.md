# 《洞见》开场分镜：渝灯穿行四时代

定位：约 55–60 秒、可点击跳过的像素风片头。它不是先替玩家讲完历史，而是让渝灯“听见”四段未散的回声；最后落到洪崖洞，引出主角嫌传单阿姨烦、想抄近路的现有序章。不要在片头提前说主角误触石扣；石扣留给第一关的玩家亲自碰到。

画面规则：先用纯场景图交代地点，再用对应 `travel` 画面交代渝灯穿行。每张图以缓慢横移、局部放大、光点粒子和一次短切换组成镜头，不让整张静态图停太久。字幕每次最多两行，放在下方安全区，不压住渝灯的脸。除片头第一句外，旁白也可仅以字幕呈现。
