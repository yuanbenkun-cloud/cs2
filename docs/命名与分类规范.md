## 五、动画与输入（活用 Godot 内置）
- 角色行动：AnimatedSprite2D + SpriteFrames（待机/走/跳/交互），帧率 6-12fps，Loop 按动作
- 输入：只认 InputMap 动作（已在 project.godot）：move_left/move_right/jump/interact；改键在 `项目设置→输入映射` 里改动作绑定的物理键即可，脚本零改动
- 对话框/UI：Control 体系 + 主题默认字体（像素字体全局）
